# Third-party notices: homebrew ROMs

This file lists the SDK runtime code that the release build
(`.github/workflows/release-assets.yml`) links into each shipped ROM.
Build-only tools such as compilers, assemblers, linkers and header fixers
are not listed because they are not copied into the ROMs. The linked code was
taken from linker maps of local builds on 2026-11-19, not from release CI:
C64 with Homebrew cc65 2.19, and GBA and N64 in the same Docker images as CI.
SNES was not built locally. Each licence is cited from the upstream source,
pinned to a commit where one is known. Items marked **to verify** could not be
confirmed and need follow-up.

## ROMs with no third-party runtime

- **Game Boy** (`chipviz-gb.gb`): hand-written RGBDS assembly
  (`cores/gb/homebrew`). Only RGBDS tools are used (`rgbasm`, `rgblink`,
  `rgbfix`), and no library is linked.
- **NES** (`chipviz-nes.nes`): hand-written ca65 assembly linked by `ld65` with
  the repository's `nes.cfg`. No cc65 library is linked.
- **Genesis** (`chipviz-genesis.md`) and **Master System** (`chipviz-sms.sms`):
  generated byte by byte by `shared/tools/build_homebrew.py`.

## Commodore 64 (`chipviz-c64.prg`): cc65 runtime

`c64.lib` (for example `crt0.o`, `conio.o` and the arithmetic helpers). cc65 is

`e356bf3f56f7afbf7e5246329562f145965cfdfc`. The linker map pulls members from
`libdragon.a`, `libdragonsys.a` and newlib's `libc.a`.

  - **libcart** (`cart.o`), adapted for libdragon from
    <https://github.com/devwizard64/libcart>. Libdragon commit
    [`08ab2f7`](https://github.com/DragonMinded/libdragon/commit/08ab2f7857d1c2673733f98e44ad26c4cf7b2abf)

    <https://github.com/buu342/N64-UNFLoader>. Libdragon commit
    [`75c00cd`](https://github.com/DragonMinded/libdragon/commit/75c00cdba67292119a06db55afff20ecbf07c607)

  sources under several licences, and some of them require their copyright
  notices to be reproduced with binary distributions. The aggregate licence
  file is included as
  [newlib-COPYING.NEWLIB.txt](newlib-COPYING.NEWLIB.txt) (release asset

  (<https://sourceware.org/git/?p=newlib-cygwin.git;a=blob_plain;f=COPYING.NEWLIB;hb=refs/tags/newlib-4.6.0>).
  It contains every section of the 4.4.0 file and adds sections (57) and (58).
  The only other change is that one target name in section (44) is reworded.
  **To verify:** the per-file notices of the linked newlib members.
- **libgcc** (MIPS, GCC 16.2.0 from the libdragon toolchain). The GCC startup
  files `crti.o`, `crtbegin.o`, `crtend.o` and `crtn.o` are linked. `libgcc.a`
  is searched, but the map shows no members pulled in. These are under the GPL

## Super Nintendo (`chipviz-snes.sfc`): PVSnesLib

Built with PVSnesLib commit `d0bd46bc70c16a4cb9c8d40a90468e18a6de9b1c`.
PVSnesLib's `snes_rules` passes every object in `pvsneslib/lib/<rom type>` to
`wlalink -d`, which discards unreferenced sections. The header template
`devkitsnes/include/hdr.asm` is copied into the build.
